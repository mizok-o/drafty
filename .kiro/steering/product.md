# Product Overview

Drafty is a document management application that allows users to create, edit, and manage documents collaboratively. The application features real-time editing capabilities through WebSocket connections and provides a clean interface for document management.

## Core Features
- Document creation and editing
- Real-time collaboration via WebSockets
- User management and authentication
- Document publishing workflow
- RESTful API with Swagger documentation

## Target Users
Content creators, writers, and teams who need collaborative document editing and management capabilities.
